Answers to the questions everyone asks first. Click a question to open it.

What is the first thing I should do after opening the app?
Go to the Settings page. If your dashboard is empty, this is expected for first-time users. You need to add your SAM.gov API key before contracts can be retrieved.
How do I log in?
The username is always radar. The password is set by your administrator — ask them for it. Your browser remembers it after the first sign-in.
How do I get a SAM.gov API key?
  1. Sign in to your SAM.gov account.
  2. Open Account Details.
  3. Request a SAM.gov API key.
  4. Wait for the confirmation email containing your API key.
  5. Copy the API key and paste it into the SAM.gov API Key field in SAM Radar's Settings.
How do I configure email notifications?
In Settings, scroll to the Email digest section and fill in:
  • Recipients: one or more email addresses, separated by commas.
  • Gmail address (sender): the account the digest sends from. You must have access to it.
  • Gmail app password: a 16-character password generated in that Google account's security settings. This is not the account's normal password.
  • Daily digest time: when the email goes out each day.
What settings can I customize?
  • NAICS codes, by entering multiple codes separated by commas.
  • Keywords, by entering multiple search terms separated by commas.
  • Minimum digest score.
  • How far back SAM Radar searches for contract opportunities.
  • Which agencies count as priority agencies.
  • The daily sync and email schedule.
How does syncing work?
SAM Radar automatically runs a sync each morning at the scheduled time. During each sync, it searches SAM.gov for contracts that match your configured NAICS codes and keywords. The newest data appears once a sync finishes. You can also press Sync now at any time to run a manual search.
Why can't I sync right now?
If you've reached your daily SAM.gov API request limit, syncing will not work until your quota resets. For example, some API keys are limited to a small number of requests per day — your available quota depends on your SAM.gov account. Quotas reset daily.
How do I view contract details?
  1. Click a contract on the dashboard. A detail panel opens and stays open until you close it.
  2. Inside you'll see why it matched your criteria — the full score breakdown — plus which organization posted it, key dates, and the point of contact.
  3. Use Open on SAM.gov to view the opportunity directly on SAM.gov.
  4. Close the panel with the ✕ button or the Esc key.
Why is my dashboard empty?
An empty dashboard usually means one of the following:
  • Your SAM.gov API key has not been added.
  • No contracts match your current NAICS codes or keywords.
  • A sync has not been performed yet.
  • The app was just updated or redeployed — hosted versions start with a fresh database after each update.
After adding your API key and configuring your search criteria, run Sync now or wait for the next scheduled sync.
What do I need before I can start using SAM Radar?
Before using the app, make sure you have:
  • A valid SAM.gov API key.
  • At least one recipient email address.
  • A sender email address.
  • Your desired NAICS codes.
  • Any keywords you want to search for.
Once these are configured, run Sync now or wait for the next scheduled sync to begin receiving contract opportunities.
